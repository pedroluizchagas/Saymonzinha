# Rótulos de triagem

As skills falam em cinco papéis de triagem. Este arquivo liga cada papel ao rótulo usado nas issues deste repositório.

| Papel nas skills  | Rótulo neste repositório | Significado                                   |
| ----------------- | ------------------------ | --------------------------------------------- |
| `needs-triage`    | `needs-triage`           | O mantenedor precisa avaliar a issue          |
| `needs-info`      | `needs-info`             | Aguardando mais informações de quem abriu     |
| `ready-for-agent` | `ready-for-agent`        | Totalmente especificada, pronta para um agente |
| `ready-for-human` | `ready-for-human`        | Precisa de uma pessoa                         |
| `wontfix`         | `wontfix`                | Não será feita                                |

Quando uma skill mencionar um papel (por exemplo, "aplique o rótulo de pronta para agente"), use o rótulo correspondente desta tabela.

Para usar outro vocabulário, edite a coluna do meio.
